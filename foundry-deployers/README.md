# foundry-deployers

Foundry-side deployers for the shared Solidity test suite.

The suite imports its contract deployers from `dynamic-imports/`. Under Hardhat those are
generated by `@ignored/imports-plugin`; Foundry (used for the zkSync flow) can't consume
them, so each file here mirrors a `dynamic-imports/` path and deploys the same contract
with a plain `new`.

`yarn deployers:foundry` copies these into `dynamic-imports/` before any Foundry run.
`dynamic-imports/` is gitignored and regenerated by `hardhat compile`, so the copy only
affects Foundry/zkSync runs. Keep each `createX` signature in sync with its contract's
constructor.
